# 📊 Quant-Macro-Analyzer | 量化均值回归与债券决策系统

这是一个基于 Python 与 AkShare 的本地量化分析框架。项目包含：
1. 数据自动化获取
2. 多资产均值回归分析
3. 债券四层宏观决策模型
4. 一个轻量级的 Web UI 控制台
你无需在命令行中反复敲击脚本，只需在浏览器中点击按钮，即可拉取数据并生成带有一定深度解读的专业图表。

## ✨ 核心特性

- 一键式 Web UI：基于 Flask 的极简本地控制台，支持按钮触发脚本、实时日志回显、图表自动加载。
- 自动数据获取：自动对接 AkShare 腾讯、新浪及中债等接口，获取沪深300、中证500、中证A500、创业板指、标普500、纳斯达克100，以及 30Y/10Y 国债收益率、CPI、PMI、FDR007 等宏观数据。
- 股指均值回归模型：自动生成“对数价格+滚动中枢”、“残差 ±1.5σ”、“平滑 Z-score 时序”、“Z-score 历史分布”四联图，并附带 AR(1) 半衰期计算与动态文字解读。
- 债券四层决策模型：剥开纯粹的统计学，结合宏观基本面进行归因。依次通过 L1 绝对估值、L2 基本面与资金面归因、L3 期限结构、L4 外部约束，输出可视化的综合仓位建议。

## 🧠 核心模型逻辑说明

### 1. 股票：均值回归四步法
剥离长期趋势，度量短期情绪偏离：
- 图1（基准）：对数价格 `ln(P)` 与 750日滚动均值（绿线）。绿线向上代表多头趋势，向下代表空头趋势。
- 图2（偏离）：残差与 ±1.5σ 灰色带。
- 图3（信号）：平滑 Z-score。策略：“顺大势，逆小势”。绿线向上且 Z-score < -1.5 时是黄金坑；绿线向下且 Z-score < -1.5 时是接飞刀。
- 图4（分布）：观察资产左/右尾的厚尾特征。同时提供 `AR(1) 半衰期`，评估偏离回归所需的时间。

### 2. 债券：四层漏斗决策模型
抛弃单纯的“价格分位”，引入宏观基本面判断“收益率是否合理”：
- L1（估值）：绝对收益率历史分位（反向解读：收益率高 = 价格便宜）。
- L2（归因）：利用 `收益率 ~ CPI + PMI` 做滚动 OLS 回归。残差为正，说明实际收益率高于基本面中枢（真便宜）；叠加 FDR007 资金面趋势，判断是否值得出手。
- L3（结构）：计算 `30Y - 10Y` 期限利差，历史分位极高时拉久期（买30Y），分位极低时缩久期（买10Y）。
- L4（约束）：中美利差倒挂极深时，外部汇率压力约束央行降息空间，触发仓位打折（一票否决或仓位减半）。
